# Senior-Dev-Buddy
A pragmatic AI assistant for the command line, optimized for the daily development workflow of tycrotius.

## Features
- LLM interaction via CLI parameters.
- Pipeline context support.
- Configurable via ~/.config/dev-buddy/config.json.

Currently in active development. Please refer to the documentation for manual installation.
